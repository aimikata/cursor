# 3日間チャレンジ：スケジュール

動画ナレーションと整合した設計。ナレーション全文は `サンキューページ動画_ナレーション_全文.md` を参照。

---

## 動画内のスケジュール

| 日 | 内容 | ナレーション原文 |
|----|------|------------------|
| **Day 1** | 『発見』 | 知られていないリサーチ方法を学びます。この方法を使えば、必ず売れるテーマが見つかります。 |
| **Day 2** | 『確信』 | そのリサーチが成功の鍵であることを理解します。成功する人と失敗する人の決定的な違いが、ここで明確になります。 |
| **Day 3** | 『感動』 | ツール導入で90分で完成する体験をします。手動で10時間かかる工程が、90分で完結します。この驚きが、あなたの確信を決定づけます。 |
| **Day 4** | 実体験＆相談 | `サンキューページ動画_ナレーション_全文.md` 参照 |

---

## 渡すもの（動画と整合）

| 日 | 動画で話している内容 | 実際に渡すもの |
|----|----------------------|----------------|
| **Day 1** | 『発見』リサーチ方法を学ぶ | **リサーチの5段階フィルターのプロンプト**＋「なぜマンガか」の深掘り |
| **Day 2** | 『確信』リサーチが成功の鍵 | （後で設計） |
| **Day 3** | 『感動』90分で完成する体験（デモ） | （後で設計） |
| **Day 4** | 無料実体験＆ゴールデンルートシミュレーション相談 | 枠1日2名・事前アンケート・その日に出版可能 |

---

## 5段階フィルター（Day 1で渡すリサーチ方法）

| 段階 | 内容 |
|------|------|
| **フィルター1** | 市場データの収集（Amazon、キーワード、SNSなど） |
| **フィルター2** | 動画化確認（YouTubeで需要チェック） |
| **フィルター3** | 痛みの有無（具体的で切実な痛みか） |
| **フィルター4** | シリーズ化の可能性（複数冊書けるテーマか） |
| **フィルター5** | 競合分析（売れている本があるか） |
