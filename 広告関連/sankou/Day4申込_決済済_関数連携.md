# Day4申込 決済済 連携（関数方式）

決済確認シート（Pipedream→Stripe）のデータを見て、Day4申込のH列を「決済済」にする方法です。

---

## 照合の考え方

| 項目 | 結論 |
|------|------|
| **メールアドレス** | 一意性が高く、確実に一致する |
| **お名前** | 同姓同名の可能性あり、補助として使う |
| **おすすめ** | メールアドレスだけで照合する |

決済確認シートには Stripe 決済分のみが入るため、メールアドレスだけの照合で十分です。

---

## シート構成の確認

| シート | 列 | 内容 |
|--------|-----|------|
| **Day4申込** | A | 日時 |
| | B | 名前 |
| | C | メール |
| | D | 選択日程 |
| | E | 目標 |
| | F | 週時間 |
| | G | メッセージ |
| | H | 決済状態（ここを関数で更新） |
| | I | 決済日（任意で追加） |
| **決済確認シート** | A | 申込日時 |
| | B | メールアドレス |
| | C | お名前 |
| | D | 決済番号 |

---

## 方法1：メールアドレスだけで照合（シンプル）

### H列（決済状態）の式

2行目以降に入力（2行目の例）：

```
=IF(COUNTIF(決済確認シート!B:B, C2)>0, "決済済", "決済待ち")
```

- `C2` は Day4申込のメール（C列）
- 決済確認シートのB列に同じメールがあれば「決済済」、なければ「決済待ち」
- 下の行にコピーするときは `C2` → `C3`、`C4` … に変わるので、オートフィルでOK

### メールの大文字・小文字を揃える場合

```
=IF(COUNTIF(決済確認シート!B:B, LOWER(C2))>0, "決済済", "決済待ち")
```

※決済確認シート側も小文字で比較したい場合は、`ARRAYFORMULA(LOWER(決済確認シート!B:B))` などを用いますが、通常はそのままでも一致します。

---

## 方法2：メール＋名前で照合（より厳密）

同じメールかつ同じ名前のときだけ「決済済」にする場合：

```
=IF(SUMPRODUCT((決済確認シート!B:B=C2)*(決済確認シート!C:C=B2))>0, "決済済", "決済待ち")
```

- `C2` = Day4申込のメール
- `B2` = Day4申込の名前
- 決済確認シート B列=メール、C列=お名前

---

## 方法3：I列に決済日も入れる

### H列（決済状態）

```
=IF(COUNTIF(決済確認シート!B:B, C2)>0, "決済済", "決済待ち")
```

### I列（決済日）※ヘッダーを「決済日」に

```
=IF(COUNTIF(決済確認シート!B:B, C2)>0, INDEX(決済確認シート!A:A, MATCH(C2, 決済確認シート!B:B, 0)), "")
```

- 決済確認シートのA列（申込日時）を、該当メールの行から取得

---

## 設定手順

1. **Day4申込シート**の1行目（ヘッダー）に「決済日」を追加する場合、I列に「決済日」と入力
2. **H列**：既存の「決済待ち」などの値は削除し、上記の式を2行目に入力
3. 式を残りの行までコピー（オートフィル）
4. 既存のG列まである場合は、H列・I列の式をそのまま追加

---

## 注意点

- **決済確認シート**と**Day4申込**が同じスプレッドシート内にあること
- 決済確認シートのワークシート名が「決済確認シート」であること（別名なら式内のシート名を変更）
- 新規申込が入るたびに、H列・I列の式を下の行にコピーする必要がある  
  → 余分な行まで式を入れておくか、オートフィルで一括コピーしておくと楽

---

## まとめ

| 項目 | 推奨 |
|------|------|
| 照合 | メールアドレス（C列）のみ |
| H列 | `=IF(COUNTIF(決済確認シート!B:B, C2)>0, "決済済", "決済待ち")` |
| I列 | 決済日を入れたい場合のみ追加 |
