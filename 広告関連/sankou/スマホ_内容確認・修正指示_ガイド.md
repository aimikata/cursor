## 2. スマホで修正指示を出すときの例文

Cursor のチャットやメモに、次のように書いて指示できます。

### パターンA：箇所指定で修正

```
メール・コンテンツ/Day1_メール本文.md の「結論：狙うべきは、マンガ市場です。」の直後に、
「LPにマンガを導入した企業の約8割が効果を実感しているという調査もあります。」
を追加して。
```

### パターンB：文言の置き換え

```
メール・コンテンツ/Day2_メール本文.md の「今日のアクション」に、
産後ダイエットの具体例（「産後ダイエットで3キロ戻ってしまった30代ママが、90日で目標達成する話」）
を追加して。
```

### パターンC：ファイル全体の方向性

```
メール・コンテンツ/Day3_メール本文.md の「今日のアクション」に、
「あなたの【約束の一行】を、心に留めておく → Day4の相談で、その一行を一緒に形にします」
を追加して。
```

### パターンD：複数ファイル

```
Day1〜Day3 の Day4案内に
「ゴールデンルートシミュレーション相談」を追加して。
```

## 4. 動画を作るかどうか（判断用）

### 現状の動画

| 種類 | URL | 用途 |
|------|-----|------|
| **サンキューページ動画** | https://youtu.be/fo90zVEWTNY | 約12分。登録後すぐに視聴。ebook・3日間チャレンジ・Day4案内 |

### 追加動画の候補と判断軸

| 候補 | 目的 | 作るメリット | 作らない場合 |
|------|------|--------------|--------------|
| **Day1用動画** | 5段階フィルターの解説 | メールだけでなく体験としてイメージしやすい | メール本文＋プロンプトで完結 |
| **Day2用動画** | リサーチの重要性・具体例 | 感動・納得感が増す | テキストだけで伝える |
| **Day3用動画** | 90分で1冊のデモ | 体験のイメージがつきやすい | 説明文＋Day4誘導で完結 |
| **「なぜマンガか」の短尺** | 本編に差し込む | マンガ市場の説得力UP | 本編のナレーション追加で対応 |

### 判断の目安

| 方針 | 条件 |
|------|------|
| **いまは作らない** | テキスト（メール＋ebook）で十分見えている／工数・コストを抑えたい |
| **1本だけ追加** | 「なぜマンガか」を本編に差し込むナレーション追加（既存動画の修正に近い） |
| **Day別に作る** | 開封率・CVRを上げたい／動画コンテンツを資産にしたい |

### 動画作成の前段階

動画を作る前に、**ナレーション台本**を固めるのがおすすめです。

- 台本：`サンキューページ動画_ナレーション_全文.md` をベースに追記・修正
- 既存の書き起こし：`1-1creative動画書き起こし.txt`、`5-1creative動画書き起こし.txt` など

## 5. スマホでの運用フロー（例）

1. **確認**：通勤中などに `メール・コンテンツ/Day1_メール本文.md` などを開いて内容を読む
2. **メモ**：気になった点をこのファイルの「修正候補」に追記する
3. **指示**：PCに戻ったとき、または Cursor Mobile で「〇〇を△△に修正して」と指示する
4. **反映**：修正後、このガイドのチェックリストに ✓ を入れる
