## インストール手順

### Windows

1. 「今すぐダウンロード」リンクをクリック
2. 「ファイルを保存」をクリック
3. ダウンロードフォルダに保存されたら、インストーラーをダブルクリック
4. ライセンス契約を確認し、「同意する」をクリック
5. インストール先を確認し、「インストール」をクリック
6. 完了後、「終了」をクリック

### Mac

1. 「今すぐダウンロード」リンクをクリック
2. ダウンロード後、インストーラーをダブルクリック
3. 「続行」→ ライセンス契約で「同意する」
4. 「インストール」をクリック
5. 完了後、「閉じる」をクリック

---

## 起動方法

- **Windows**: Windows キー → 「Amazon」→「Kindle Create」
- **Mac**: Launchpad → 「Kindle Create」

---

## 日本語表示に変える（任意）

1. 「Help」→「Settings」→「Language」（Windows）または「Kindle Create」→「Preferences」→「Language」（Mac）
2. 「日本語」を選択
3. 「Save」をクリック

---

## マンガ用としての使い方

Kindle Create は、PDF または複数の JPEG ファイルからマンガ形式の電子書籍を作成できます。当日の実体験で一緒に操作します。
