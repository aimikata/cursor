# 動画・3日間チャレンジ：再検討メモ

## 検討のきっかけ

1. 動画では「Kindle電子書籍」として話しているが「マンガ」が出てこない
2. ebook受け取ったら勝手に3日間チャレンジが始まる流れでいいのか
3. Day4の案内で「書籍」と言っているが実際は「マンガ」を持ち帰る。齟齬はないか
4. 持ち帰れるものの価値・魅力が十分に期待できる最後の案内になっているか

---

## 1. マンガが抜けていた／いきなり3日間チャレンジで言っていいのか

### 現状
- 動画本編：「Kindle電子書籍」「印税」「1冊」という言葉で統一
- 3日間チャレンジ案内：「Day1は発見」「Day2は確信」「Day3は感動」→「マンガ」は出てこない
- 実際のDay4：**マンガ1冊**を持ち帰れる

### 結論：**いきなり3日間チャレンジで「マンガ」を出すのは不自然**

- 視聴者は「電子書籍＝文章の本」と解釈している可能性が高い
- Day4で「マンガを持ち帰れる」と言っても、「え、マンガ？何の話？」となりかねない
- **動画の本編（3日間チャレンジの前）に「なぜマンガか」を入れるべき**

### 挿入位置の候補
- **5段階フィルターの直後、3日間チャレンジ案内の直前**が自然
- 「市場が求めているテーマを選ぶ」→「電子書籍の中でも、なぜマンガなのか」→「3日間で学びます」の流れ
- ※ナレーションは `サンキューページ動画_ナレーション_全文.md` に一本化。実際は誤解その2にマンガのにおわせを入れる形で対応済み。

## 2. ebook受け取ったら勝手に3日間チャレンジが始まる流れ

### 現状
- 動画：「明日の朝9時に、Day1のメールをお送りします」
- 追加の申し込みなしで、登録＝3日間チャレンジ参加

### 検討

| 観点 | 評価 |
|------|------|
| **メリット** | ハードルが低い。迷わない。スムーズ。離脱ポイントが少ない。 |
| **デメリット** | 参加したくない人にもメールが届く。ただし、動画を見終わった時点で興味がなければ離脱するか、メールを無視する。 |
| **一貫性** | 「このビデオは完全にマスターするための完全ガイドです」→「明日から3日間で学びます」で、**受け取った＝参加する**という流れは自然。 |

### 結論：**この流れで問題ない**

- 8番の型でも「ebook無料→LP→サンキュー動画」で、動画の最後に有料オファーを出す。御社は「有料」ではなく「無料の3日間チャレンジ」なので、ハードルはさらに低い。
- 登録した時点で「無料の価値を受け取る」という約束。3日間のメールはその履行。
- ただし、**Day4は希望者のみ・事前アンケート**なので、ここで選別される。全体の流れは一貫している。

## 3. Day4の案内：「書籍」vs「マンガ」の齟齬

### 現状
（ナレーションは `サンキューページ動画_ナレーション_全文.md` 参照）

### 実際
- **マンガ1冊**を持ち帰れる（その日に出版可能）

### 齟齬の有無
- 「1冊」は中立的なので、書籍でもマンガでも解釈可能
- **ただし**：動画本編で「マンガ」を一度も言っていないと、「1冊」が何を指すか曖昧
- ユーザー見解：書籍よりマンガの方が驚きと喜びと価値がある。グレードアップなので問題ない。

### 結論：**「マンガ」と明言した方が期待値が上がる**

- 本編で「なぜマンガか」を入れたうえで、Day4で「あなたのマンガ1冊を、その日のうちに出版できる」と伝えると、一貫し、期待も高まる。
- 「書籍」→「マンガ」に変えることで、**デメリットはない**（価値が上がるだけ）。

## 4. 持ち帰れるものの価値・魅力が十分に期待できるか

### 現状のDay4案内の課題
- 「あなた専用の『仕組み』がひとつ、増える」→ 抽象的で、**何が増えるか**が伝わりにくい
- 「出版できます」→ どういう形で手に入るか（データ？紙？Amazonに並ぶ？）が曖昧

### 改善の方向性

| 現状 | 改善案 |
|------|--------|
| この日、あなたが作る1冊は、そのままあなたの資産として出版できます | **この日、あなたが作るマンガ1冊は、そのままあなたの資産として出版できます。その日のうちに、Amazonに並びます。** |
| その日のうちに、あなた専用の「仕組み」がひとつ、増えるんです | **つまり、体験したその日に、あなたのマンガ1冊が、売れ続ける資産になるんです。** |

### 価値・魅力を伝える要素（過不足チェック）

| 要素 | 現状 | 推奨 |
|------|------|------|
| **何ができるか** | 1冊を作る・出版できる | マンガ1冊を作り、その日に出版できる |
| **持ち帰れるもの** | 暗黙（出版＝資産） | **あなたのマンガ1冊がAmazonに並ぶ**と明言 |
| **時間感** | その日のうちに | その日のうちに（維持） |
| **希少性** | 枠1日2名・事前アンケート | 維持（良い） |
| **驚き** | やや弱い | 「絵が描けなくても、90分でマンガ1冊」を入れると強い |
