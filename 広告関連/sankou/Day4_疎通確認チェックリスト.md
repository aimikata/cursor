# Day4 疎通確認チェックリスト

シートは自動作成されるため、事前準備不要で疎通確認できます。

---

## 1. 事前準備

| 項目 | 確認 |
|------|------|
| **GAS** | `GAS_新フォーム_整理後.gs` の内容を 新フォーム.gs にコピー済み |
| **デプロイ** | デプロイを更新（「バージョン」→「新バージョン」または「デプロイを管理」→「編集」→「バージョン：新バージョン」） |
| **スプレッドシート** | 空き日程シートに `status` が `available` の行が1件以上ある |

---

## 2. 疎通確認の流れ

### ① 空き日程の取得（GET）

1. ブラウザで以下を開く：
   ```
   https://script.google.com/macros/s/AKfycbzvdzj7BwBHVy48cjHb7OjIw8px9_VOPqOTd7lPPWZn8EzxgC-5uVw705Na6TEwlORv/exec?action=schedule
   ```
2. 空き日程が JSON で返ってくる（`[]` や `[{date, timeDisplay, row}, ...]`）ことを確認

---

### ② Day4 申込（POST）

1. day4-anketo.html を開く  
   - 例：`https://cursor0113.vercel.app/lp-consultation/day4-anketo.html`
2. 参加希望の日程を選択
3. 名前・メールを入力して「申込して決済へ進む」をクリック
4. 「申込を受け付けました」＋「決済ページへ」ボタンが表示されることを確認
5. スプレッドシートに「Day4申込」シートが自動作成され、1行追記されていることを確認
6. 空き日程シートの該当枠が「済」になっていることを確認

---

### ③ Stripe 決済（手動）

1. 表示された「決済ページへ」ボタンをクリック
2. Stripe 決済画面でテスト決済（または本番決済）を実行
3. 決済完了後、スプレッドシートの「Day4決済」シートに1行追記されることを確認

※ Stripe Webhook による自動書き出しには、以下が必要です：
- Stripe ダッシュボードで Webhook エンドポイントを登録
- GAS の `STRIPE_WEBHOOK_SECRET` に署名シークレットを設定

---

## 3. 自動作成されるシート

| シート名 | 作成タイミング |
|----------|----------------|
| **Day4申込** | 最初の Day4 申込送信時 |
| **Day4決済** | Stripe Webhook 初回受信時 |
| **ebook登録** | 最初の ebook 申込時 |
| **決済確認シート** | 個別相談の最初の申込時（既存ならそのまま使用） |

---

## 4. トラブルシュート

| 症状 | 確認ポイント |
|------|--------------|
| 空き日程が表示されない | 空き日程シートの C 列（status）が `available` または `空き` か確認 |
| 申込しても動かない | ブラウザのコンソール（F12）でエラー内容を確認 |
| Day4決済に書き出されない | Stripe Webhook の設定、GAS の `STRIPE_WEBHOOK_SECRET` を確認 |
