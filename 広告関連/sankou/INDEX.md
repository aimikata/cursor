## サブフォルダについて

`GAS/` `デプロイ・設定/` 等のサブフォルダには README があり、カテゴリの説明をしています。  
ファイルの実体は `sankou` 直下にあります。手動でサブフォルダへ移動する場合は README を参照してください。
