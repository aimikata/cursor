## 2. Stripe 本番モードの Webhook 設定

Stripe の **テストモード** と **本番モード** では Webhook が別々です。  
本番モード用の Webhook を追加する必要があります。

1. [Stripe ダッシュボード](https://dashboard.stripe.com/) にログイン
2. **画面上部のトグル** で **本番モード** に切り替え（テストモードを OFF）
3. **開発者** → **Webhook**
4. **「エンドポイントを追加」** をクリック
5. 以下を設定：

| 項目 | 値 |
|------|-----|
| **エンドポイントURL** | `https://5a6173445458cf52daf8a8ab63c70977.m.pipedream.net` |
| **リッスンするイベント** | `checkout.session.completed` |
| **説明**（任意） | Day4決済 |

6. **「エンドポイントを追加」** をクリック

## 3. Pipedream の Stripe 接続（本番用）

Pipedream の Stripe  trigger で **本番用 API キー** を使うか確認します。

### 方法A：既存ワークフローで本番接続に切り替え

1. Pipedream → **Stripe Checkout to Google Sheets** ワークフローを開く
2. **Trigger**（紫の Stripe ノード）をクリック
3. **Stripe Account** の接続を確認
4. 本番用（`sk_live_...`）の接続がされていれば OK
5. テスト用のみの場合は、**新規接続**で本番用キーを追加

### 方法B：本番用アカウントを追加

1. Trigger 設定で **「Connect a Stripe account」** をクリック
2. **「Create new connection」** を選択
3. 接続名：`Day4本番用`
4. **Restricted API Key** に Stripe 本番の **シークレットキー**（`sk_live_...`）を入力
5. **Save** で保存
6. Trigger の **Stripe Account** で `Day4本番用` を選択
7. **Deploy** で再デプロイ

※ 同じ Webhook URL がテスト・本番の両方のイベントを受け取ります。Stripe 接続を本番キーにすると、本番決済のデータが正しく処理されます。
