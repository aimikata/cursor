    - 原因：インターネット接続の問題、ファイアウォールのブロック
    - 解決法：接続を確認、ファイアウォール設定を確認

  - Windowsの場合：
    - 管理者権限で実行
    - ウイルス対策ソフトの例外リストに追加
    - コマンドプロンプトから起動：`"C:\Users\[ユーザー名]\AppData\Local\Programs\cursor\Cursor.exe"`

  **問題3：動作が遅い**
  - 設定→拡張機能→不要な拡張機能を無効化
  - 設定→エディタ→「Large file optimization」を有効化
  - システムのメモリとCPU使用率を確認
