    log_file = "daily_log.txt"
    try:
        with open(log_file, "r", encoding="utf-8") as f:
            for line in f:
                if line.startswith(day):
                    print(line.rstrip())
    except FileNotFoundError:
        print(f"No log file found: {log_file}")
    return

**【マンガパート】**

**マンガシーン5-1（ページ13）：**
- **パネル1：** アレックスが「`--day`で何もヒットしなかったときに、『その日のログはありません』って出したい」と言う。
- **デイビッド：** 「それ、**Composerに追加で指示**すればいい。『`--day`で該当行が0件のとき、”その日のログはありません”と表示して』って、**同じComposerのスレッド**に書いて、もう一度Generateすれば、その変更だけ足してくれる。」

**パネル2：** アレックスがComposerに追記して送信する。「`--day`で該当する行が1件もないとき、`その日のログはありません`と表示して。」
- **Cursor（Composer）：** 既存の`--day`処理に、ループ後に件数チェックを足し、0件なら「その日のログはありません」を出力するような差分を提案する。
- **アレックス：** 「**追加プロンプト**で、細かい挙動を変えられるんだ。」

**パネル3：** デイビッドが「**全部Acceptしなくてもいい**」と補足する。
- **デイビッド：** 「変更が複数ブロックに分かれてる場合、**気に入ったブロックだけAccept**して、あとは手で直す、ってやり方もできる。**生成はあくまで助け**で、最終的な判断は自分でするんだよ。」

**【インフォグラフィックパート】**

**ページ13-14：**
- **カスタマイズのやり方：**
  - **追加プロンプト：** 同じスレッドで「〇〇のときは××して」と書き足し、再Generate
  - **部分的にAccept：** 提案のうち、使いたいブロックだけAcceptし、残りは却下して自分で編集
  - **手で直す：** Acceptしたあと、エディタで微修正してOK
- **ポイント：** Composerの提案を**そのまま使う**も**部分的に使う**も、**自分で直す**もできる。**段階的に頼る**と扱いやすい。

### **セクション5.5：Agentモードの実践的な活用（ページ15-17）**

- **デイビッド：** 「**Normal**は、説明に基づいてコードを生成する。いまやってきたのはこっち。**Agent**は、**段階的に考えて、ターミナルでコマンドを実行したり**できる。『生成したあと、`python log.py --day 今日の日付`で動かして確認して』みたいに**実行まで任せられる**。」

**パネル2：** アレックスがComposerで**Agent**に切り替え、同じ`daily_log`フォルダを開いた状態で「`log.py`に`--day`機能を足して、`python log.py --day 2025-01-21`で動作確認までして」と入力する。
- **視覚的表現：** Agentが「Step 1: log.py を変更」「Step 2: ターミナルで実行」のような**思考ステップ**を表示し、続けてターミナルが開き、`python log.py --day 2025-01-21`が実行される。
- **デイビッド：** 「**実行まで任せる**と、『動いた／動かなかった』がその場でわかる。ただ、**どのコマンドを打つか**は自分でも把握しておくこと。Agentの詳しい使い方は**Chapter 8**でやるよ。」

**パネル3：** アレックスがAgentの実行結果（その日の行が表示された様子）を見て、「生成と確認がまとめてできるんだ」と感心する。
- **デイビッド：** 「**小さな変更＋実行確認**ならAgentが便利。**大きな設計**や**複数ファイルの整理**は、まずNormalでじっくり提案を見てから、って使い分けがおすすめ。」

**【インフォグラフィックパート】**

**ページ16-17：**
- **Normal vs Agent（Composer）：**
  - **Normal：** 説明 → コード生成・差分表示 → 自分でAccept／実行して確認
  - **Agent：** 説明 → 段階的に思考 → コード変更 **＋ ターミナル実行など**まで行う場合がある
- **Agentをどこで使うか：** 生成後の**実行・簡単なテスト**まで任せたいとき。**何をやるか**は指示ではっきり書く。
- **詳細はChapter 8：** Agentの考え方や、バグ修正・テストとの組み合わせなどは、あとで掘り下げる。
