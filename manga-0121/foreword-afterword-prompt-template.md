# 「はじめに」と「あとがき」プロンプトテンプレート

> **目的：** ハウツー本用の魅力的な前書きと後書きを生成するための汎用プロンプト  
> **ポイント：** 読者が「中身を読みたくなる仕掛け」を組み込む

---

## 📖 「はじめに」生成プロンプト

### 基本情報（プロンプト使用前に埋める）

```
【本のタイトル】: ___________
【ターゲット読者】: ___________（例：プログラミング初心者、起業を目指すビジネスパーソン）
【読者が抱える問題】: ___________（例：コードを書くのに時間がかかる、何から始めればいいかわからない）
【この本で得られる成果】: ___________（例：AIを使って10倍速くコードを書けるようになる）
【著者の体験・ストーリー】: ___________（例：私も3年前は同じ悩みを抱えていました...）
【特徴的な章・内容】: ___________（例：第5章のComposer機能、第10章のリファクタリング実践）
【読了後の読者の姿】: ___________（例：自信を持ってAI開発ツールを使いこなせる）
```

### 生成プロンプト

```markdown
# 「はじめに」生成プロンプト

以下の情報を基に、読者が「今すぐ本文を読みたい！」と思う魅力的な「はじめに」（2-3ページ、約1000-1500語）を作成してください。

## 入力情報
- **本のタイトル**: {本のタイトル}
- **ターゲット読者**: {ターゲット読者}
- **読者が抱える問題**: {読者が抱える問題}
- **この本で得られる成果**: {この本で得られる成果}
- **著者の体験・ストーリー**: {著者の体験・ストーリー}
- **特徴的な章・内容**: {特徴的な章・内容}
- **読了後の読者の姿**: {読了後の読者の姿}

## 構成（以下の5セクションで構成）

### 1. オープニング：読者への共感（問題提起）
**目的**: 読者の心を掴む。「この本は自分のための本だ」と思わせる。

**含めるべき要素**:
- 読者が日々感じている具体的な悩みや課題を描写
- 「もしこんな経験があるなら、この本はあなたのためのものです」という共感の言葉
- 具体的なシーン描写（例：「深夜2時、エラーメッセージと格闘しているあなた...」）
- 読者の感情に訴えかける表現

**仕掛け**: 読者が「これ、まさに自分のことだ！」と感じる具体的な描写

---

### 2. 転機：この本との出会い（著者の体験）
**目的**: 著者の信頼性を確立し、読者に希望を与える。

**含めるべき要素**:
- 著者自身が同じ問題を抱えていたストーリー
- 転機となった出来事や発見
- 失敗談や試行錯誤のエピソード（共感を呼ぶ）
- 具体的な数字や成果（例：「3ヶ月でコーディング速度が10倍に」）
- 「あなたにもできる」というメッセージ

**仕掛け**: ビフォー・アフターの劇的な変化を示し、読者に「自分も変われるかも」と期待させる

---

### 3. 本書の価値：この本で得られること（ベネフィット）
**目的**: 本書の独自性と具体的な価値を明確に伝える。

**含めるべき要素**:
- この本でしか得られない独自の内容
- 各章で学べる具体的なスキルや知識（ティーザー）
- 他の本や教材との違い（なぜこの本なのか）
- 読了後に読者ができるようになること（具体的に3-5個）
- 実践的な内容であることの強調

**仕掛け**: 
- 各章のハイライトを魅力的に紹介（ネタバレしない程度に）
- 「第5章では、〇〇の秘密を公開します」のような予告
- 読者が「早く読みたい！」と思う具体的な成果の提示

**例**:
「この本を読み終える頃には、あなたは...
- ✓ AIツールを使って、たった10分でウェブアプリを作れるようになります
- ✓ エラーに悩む時間が90%削減されます
- ✓ 自信を持ってコードをレビューに出せるようになります」

---

### 4. 読み方ガイド：本書の構成と活用法
**目的**: 読者が効率的に学べるよう導く。

**含めるべき要素**:
- 本書の全体構造（章立ての紹介）
- 推奨される読み方（順番に読む？必要な章から？）
- 初心者と経験者で読み方を変える提案
- 実践しながら読む方法の提案
- サンプルコードやリソースの場所

**仕掛け**: 「あなたのレベルに合わせた読み方」を提案し、全読者に「この本は自分に合っている」と感じさせる

---

### 5. クロージング：読者への期待と励まし
**目的**: 読者のモチベーションを最高潮に高め、本文へ誘導する。

**含めるべき要素**:
- 読者への期待と信頼のメッセージ
- 「一緒に学びの旅に出かけましょう」という誘い
- 学習における心構えや姿勢のアドバイス
- 困難に直面した時の励まし
- 「さあ、始めましょう！」という行動喚起

**仕掛け**: 
- 感情を揺さぶる力強いメッセージ
- 読者が「よし、やるぞ！」と思える言葉
- 本文への自然な導線

---

## 文体・トーン

- **親しみやすく、でもプロフェッショナル**: 友人に話しかけるような温かさと、専門家としての信頼性を両立
- **具体的で視覚的**: 抽象的な表現ではなく、具体的なシーンや数字を使う
- **ポジティブで励まし**: 読者を勇気づけ、行動を促す
- **ストーリーテリング**: 物語の要素を取り入れ、読者を引き込む

## 避けるべき表現

- ❌ 抽象的で曖昧な表現（「素晴らしい」「便利」だけでは不十分）
- ❌ 誇大広告的な表現（「これさえあれば全て解決！」など）
- ❌ 専門用語の羅列（読者を置いていかない）
- ❌ 長すぎる文章（1文は短く、リズムよく）

## 最終チェック項目

- [ ] 読者が「自分のための本だ」と感じる共感ポイントがあるか？
- [ ] 著者の体験ストーリーが具体的で信頼できるか？
- [ ] 本書の独自性と価値が明確に伝わるか？
- [ ] 各章の内容が魅力的に紹介されているか（ティーザー）？
- [ ] 読者が「今すぐ読みたい！」と思う仕掛けがあるか？
- [ ] 文章が読みやすく、リズムがあるか？
- [ ] 最後に強い行動喚起があるか？
```

## 📖 「あとがき」生成プロンプト

### 基本情報（プロンプト使用前に埋める）

```
【本のタイトル】: ___________
【読者が達成したこと】: ___________（例：AIツールを使いこなせるようになった）
【著者の最終メッセージ】: ___________（例：学び続けることの大切さ）
【次のステップ】: ___________（例：実際のプロジェクトで実践、コミュニティ参加）
【追加リソース】: ___________（例：公式サイト、GitHub、コミュニティURL）
【感謝の言葉】: ___________（例：読者、協力者、家族への感謝）
```

### 生成プロンプト

```markdown
# 「あとがき」生成プロンプト

以下の情報を基に、読者が「読んで良かった！次も頑張ろう！」と思える感動的な「あとがき」（1-2ページ、約500-800語）を作成してください。

## 入力情報
- **本のタイトル**: {本のタイトル}
- **読者が達成したこと**: {読者が達成したこと}
- **著者の最終メッセージ**: {著者の最終メッセージ}
- **次のステップ**: {次のステップ}
- **追加リソース**: {追加リソース}
- **感謝の言葉**: {感謝の言葉}

## 構成（以下の5セクションで構成）

### 1. オープニング：読了への感謝と祝福
**目的**: 読者の達成を称え、感情的なつながりを作る。

**含めるべき要素**:
- 本を最後まで読んでくれたことへの心からの感謝
- 読者の努力と成長を称える言葉
- 読了は終わりではなく、新しい始まりであることを示唆
- 読者が本書で得た具体的なスキルや知識の再確認

**仕掛け**: 読者が「やり遂げた！」という達成感を味わえる祝福のメッセージ

---

### 2. 振り返り：共に歩んだ旅路
**目的**: 読者と一緒に本書の内容を振り返り、学びを定着させる。

**含めるべき要素**:
- 本書で扱った主要なトピックの簡潔なまとめ
- 各章で学んだ重要なポイントのハイライト
- 読者が「はじめに」で抱えていた問題が今どう解決されたか
- 読者の成長の軌跡を言語化

**仕掛け**: ビフォー・アフターを振り返らせ、読者自身の成長を実感させる

---

### 3. 著者の思い：この本に込めたメッセージ
**目的**: 著者の本音を伝え、読者との絆を深める。

**含めるべき要素**:
- なぜこの本を書いたのか（著者の動機）
- 執筆中のエピソードや裏話
- 読者に最も伝えたかったメッセージ
- 著者自身の継続的な学びの姿勢
- 読者へのエールと信頼のメッセージ

**仕掛け**: 
- 著者の人間味を感じさせるエピソード
- 「あなたならできる」という力強い信頼のメッセージ
- 読者が「著者と一緒に学べて良かった」と感じる内容

---

### 4. 次のステップ：ここからの旅立ち
**目的**: 読者を次の行動へ導く。学びを継続させる。

**含めるべき要素**:
- 本書で学んだことを実践する具体的な方法
- 次に学ぶべきトピックや読むべき本の提案
- コミュニティやリソースの紹介
- 継続的な学習のためのアドバイス
- 「小さく始めて、継続する」ことの重要性

**追加リソースの例**:
- 公式サイト: [URL]
- GitHubリポジトリ: [URL]
- コミュニティ: [Discord/Slack/Forum URL]
- 著者のSNS: [Twitter/LinkedIn]
- サンプルコード: [GitHub URL]
- 追加チュートリアル: [URL]

**仕掛け**: 
- 具体的で実行可能な「次の一歩」を提示
- 読者が「今すぐやってみよう」と思えるアクションアイテム
- コミュニティへの誘導で孤独感を解消

---

### 5. クロージング：感謝と励ましの最終メッセージ
**目的**: 感動的に締めくくり、読者の心に残る言葉を残す。

**含めるべき要素**:
- 読者への深い感謝
- 協力者、レビュアー、家族への感謝
- 読者の未来への期待と祝福
- 最後の励ましと応援のメッセージ
- 「あなたの成功を心から願っています」という真心

**仕掛け**: 
- 感情を込めた心からの言葉
- 読者が「読んで良かった」と心から思える締めくくり
- 「また会いましょう」という次への期待

---

## 文体・トーン

- **温かく、心からの感謝**: 読者との絆を深める温かいトーン
- **前向きで励まし**: 読者の未来を信じる力強いメッセージ
- **個人的で親密**: 一人ひとりの読者に語りかけるような文体
- **感情的で人間味**: 著者の本音や感情を素直に表現

## 避けるべき表現

- ❌ 形式的で事務的な感謝（心がこもっていない）
- ❌ 新しい複雑な概念の導入（あとがきは復習と励まし）
- ❌ 営業的な次作の宣伝（自然な形での紹介はOK）
- ❌ 長すぎる文章（簡潔に、でも心を込めて）

## 最終チェック項目

- [ ] 読者が達成感を味わえる祝福のメッセージがあるか？
- [ ] 本書の内容が簡潔に振り返られているか？
- [ ] 著者の本音や人間味が伝わるか？
- [ ] 次のステップが具体的で実行可能か？
- [ ] 追加リソースが役立つ形で提示されているか？
- [ ] 読者への感謝が心から伝わるか？
- [ ] 最後に感動的で力強いメッセージがあるか？
```

---

## 💡 使い方

### ステップ1：基本情報を埋める
各プロンプトの「基本情報」セクションに、あなたの本の具体的な情報を記入します。

### ステップ2：プロンプトをAIに入力
記入した情報と共に、生成プロンプト全体をAI（Claude、ChatGPT等）に入力します。

### ステップ3：生成結果を確認・修正
AIが生成した「はじめに」「あとがき」を確認し、必要に応じて修正・調整します。

### ステップ4：最終チェック
最終チェック項目を使って、すべての重要要素が含まれているか確認します。

## 📝 例：Cursor IDE本の場合

### 「はじめに」の基本情報（例）

```
【本のタイトル】: Learn Cursor IDE: The Visual Guide to AI-Powered Development
【ターゲット読者】: プログラミング初心者〜中級者、AIツールを使いたい開発者
【読者が抱える問題】: コードを書くのに時間がかかる、エラー解決に悩む、AIツールの使い方がわからない
【この本で得られる成果】: Cursor IDEを使って10倍速くコードを書けるようになる、AIと協働する新しい開発スタイルを習得
【著者の体験・ストーリー】: 私も3年前はVS Codeで深夜までコーディングしていました。Cursorと出会い、開発速度が劇的に向上した体験を共有したい
【特徴的な章・内容】: マンガ形式で学べる、実践的なプロジェクト（ToDoアプリ、API連携、データベース）、初心者でも理解できる丁寧な説明
【読了後の読者の姿】: 自信を持ってAIツールを使いこなし、エラーに悩む時間が激減し、楽しくコーディングできる
```

### 「あとがき」の基本情報（例）

```
【本のタイトル】: Learn Cursor IDE: The Visual Guide to AI-Powered Development
【読者が達成したこと】: Cursor IDEの全機能を理解し、実際のプロジェクトで実践できるスキルを習得
【著者の最終メッセージ】: AIは敵ではなく、最高のパートナー。学び続けることで、さらに成長できる
【次のステップ】: 実際のプロジェクトでCursorを使う、コミュニティで経験を共有、新しいAIツールも試してみる
【追加リソース】: 公式サイト（cursor.sh）、著者のGitHub、Cursorコミュニティ（Discord）
【感謝の言葉】: 最後まで読んでくださった読者の皆様、レビューしてくれた仲間たち、そして家族に感謝
```

## ✨ 重要なポイント

### 「はじめに」の成功の鍵
1. **共感**: 読者の悩みを的確に言語化する
2. **ストーリー**: 著者の体験談で信頼性を確立
3. **ティーザー**: 各章の魅力的な内容を予告
4. **行動喚起**: 「今すぐ読みたい！」と思わせる

### 「あとがき」の成功の鍵
1. **祝福**: 読者の達成を心から称える
2. **振り返り**: 学びの旅を共に振り返る
3. **次のステップ**: 具体的で実行可能な行動を提示
4. **感謝**: 心からの感謝で感動的に締めくくる

---

このテンプレートを使えば、どんなハウツー本でも「読者が読みたくなる」魅力的な前書きと後書きを作成できます。
