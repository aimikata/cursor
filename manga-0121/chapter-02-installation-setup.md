**【Text Part - Detailed Explanation】**

**Pages 10-11, bottom:**
- **Steps to get an API key (Claude):**

  2. Create an account or log in
  3. Open the "API Keys" section
  4. Click "Create Key"
  5. Enter a key name (e.g., "For Cursor")
  6. Copy the generated key (note: you can only see it this once!)
  7. Paste it into Cursor's API Keys settings screen and save

- **Steps to get an API key (OpenAI):**
  1. Access OpenAI's official website (platform.openai.com)
  2. Create an account or log in
  3. Open the "API Keys" section
  4. Click "Create new secret key"
  5. Enter a key name
  6. Copy the generated key
  7. Paste it into Cursor's API Keys settings screen and save

### **Section 2.3: Troubleshooting Common Issues (Pages 13-18)**

**【Manga Part】**

**Manga Scene 4-1 (Page 13):**
- **Panel 1:** When Alex tries to use Cursor, an error message appears: "API Key is not valid".
- **Alex:** "An error appeared! It says 'API key is not valid'... what should I do?"
- **Alex (thinking):** "I just set it up..."

**Panel 2:** David appears.
- **David:** "This is a common issue. There are a few things to check."
- **David (checklist):**
  1. Check if the API key was copied correctly (no extra spaces before or after)
  2. Check if the API key is set for the correct service (Claude or OpenAI)
  3. Check if the API key has an expiration date (if on a paid plan, check balance)
  4. Check if internet connection is working

**【Infographic Part】**

**Pages 13-14:**
- Common errors and solutions:
  - **"API Key is not valid"**
    - Cause: API key input error, invalid key, insufficient balance
    - Solution: Recheck key, generate new key, check balance
  - **"Connection failed"**
    - Cause: Internet connection issue, firewall blocking
    - Solution: Check connection, check firewall settings

**【Text Part - Detailed Explanation】**

**Pages 16-17, bottom:**
- **Complete troubleshooting steps for common issues:**
  
  **Issue 1: API Key Error**
  - Step 1: Open API Keys settings screen
  - Step 2: Delete current key
  - Step 3: Generate new key (on Anthropic/OpenAI website)
  - Step 4: Paste new key and save
  - Step 5: Restart Cursor

  **Issue 2: Won't Start**
  - On Mac:
    - System Preferences → Security & Privacy → General → Click "Open"
    - Launch from Terminal: `open -a Cursor`
  - On Windows:
    - Run as administrator
    - Add to antivirus exception list
    - Launch from Command Prompt: `"C:\Users\[username]\AppData\Local\Programs\cursor\Cursor.exe"`

  **Issue 3: Running Slowly**
  - Settings → Extensions → Disable unnecessary extensions
  - Settings → Editor → Enable "Large file optimization"
  - Check system memory and CPU usage
