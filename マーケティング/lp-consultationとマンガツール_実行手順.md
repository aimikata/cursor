# lp-consultation × マンガツール マーケティング実行手順

昨日までの**広告プロモーション・LP**と、**売りたいもの（マンガ生成ツール一式）**を、マーケティングのアドバイザーで「どの型が良いか」導き、**実行できる**までの流れをまとめました。

---

## 0. 知識はあるが自分では売ったことがない人へ：昨日LP動画を作り替えたあと、次は何をすべきか

**「一流のマーケティングを行う人の手伝いを10年してきたが、自分自身では何も発売しておらず、何をどうやっていいかわからなくなる」**  
という状態になっているときのための指針です。

### 陥りやすいパターン

- **形を磨き続ける** … 広告の型・LPの型・動画の型を「もっと良く」し続け、**一度もその形のまま本番で回さない**
- **次の一手を探し続ける** … 「プロモーション・広告の形をまた磨くか」「別の型を試すか」で迷い、**やることが次々増える**
- **知識が多いほど動けなくなる** … やれることが多すぎて、「何を最初にやるか」を決められない

その結果、**自分では一度も「売る」を完走していない**まま、情報とタスクだけが積み上がります。

### 昨日LPの動画を作り替えた「あと」にやること（結論）

**いったん「形をまた磨く」は止めて、今の形のまま一度回し、数字を見る。**

- **変数は増やさない** … 変えたのは「LPの中の動画」だけ。いまは**それ以外は触らない**。
- **やること** … 新しい動画を載せたLPに、**これまでと同じ広告**（または同じ予算感）でトラフィックを流す。
- **見る数字** … クリック数・相談予約数・成約数など、**すでに計測している指標**が、動画を変える前と比べてどう変わったか。

**「プロモーション・広告の形をまた磨く」のは、この数字が出てから。**

- 数字が**良くなった** → 「動画の方向性は当たっている」と判断し、次は**別の1箇所**（広告コピー or 相談予約後のメール など）だけを型に沿って磨く。
- 数字が**悪くなった or 変わらない** → 「動画のどの部分が効いていないか」を**1つだけ**仮説にして、また動画かLPの**1箇所だけ**を変えて、もう一度回して数字を見る。

「型を磨く」「次の施策を考える」は、**毎回「変えるのは1つ＋数字を見る」のあと**にすると、迷いが減ります。

### 予算がほとんどない・実験できない崖っぷちのとき

**「予算はあまりない。実験はできない。崖っぷちだ」** という場合は、**広告で流して数字を見る**はしない。  
お金をかけない「次の一歩」に切り替える。

| 方針 | やること | やらないこと |
|------|----------|---------------|
| **実験より「売上1件」** | まず**相談予約→成約を1件**つくることを最優先にする。「どの型が効くか試す」より、**確定した売上を1件**つくる。 | 広告費をかけての「テスト」・「実験」は**しない**。 |
| **広告は止める** | 予算が厳しいあいだは**広告を流さない**。クリック単価分の出費を止める。 | 「ちょっとだけ出してみる」で**予算を溶かさない**。 |
| **お金をかけずにLPを見てもらう** | 新しい動画入りLPは**出したまま**にして、**広告費ゼロ**で誰かに届ける経路を**1つだけ**作る。例：既存のメールリストに1通送る／知り合い・紹介で「この人だけ」にリンクを送る／SNS（X等）で1投稿だけしてLPのURLを載せる。 | あれこれ経路を増やさない。**1経路・1アクション**に絞る。 |
| **相談が1件来たら、その1件を成約させる** | 相談予約が**1件**でも入ったら、「その1人を成約させる」に集中する。セールストーク・相談の台本（lp-consultation の sales-talk-script 等）を**1回だけ**整え、その1件で結果を出す。 | 相談が来る前に「次の型」「次のLP」を探しに行かない。 |
| **型を磨くのは「1件成約したあと」** | 相談→成約を**1件**やり切ってから、「成約が増えるには何を磨くか」を考える。 | 成約0のうちに施策を増やさない。 |

崖っぷちだと**「実験」より「確定申告できる売上を1件つくる」**が先。  
お金をかけずに届けられる人に**1人でも**LPを見てもらい、相談が**1件**でも来たら、その1件を逃さず成約に繋げる。

---

### 今日・今週やること（最優先の1つ）

**※ 予算あり・実験できる場合**（上の「崖っぷち」に当てはまらないとき）

| 順番 | やること | やらないこと（いったん） |
|------|----------|---------------------------|
| 1 | **新しい動画を入れたLPを本番に乗せ、広告を流す** | 広告コピー・LP文言・新たな型の追加は**触らない** |
| 2 | **〇日後（例：3〜7日）に、動画変更前と同じ指標**（クリック単価・相談予約数など）**を取る** | 「まだ数字出てないから次を考えよう」で**別の改善に手を出す**のはやめる |
| 3 | 数字を見て、**良くなった／悪くなった／変わらない**のどれかをメモする | 一度に「広告もLPもメールも」変えない |

**※ 予算がほとんどない・実験できない崖っぷちの場合**は、上記ではなく**「予算がほとんどない・実験できない崖っぷちのとき」**の表に沿って動く。広告は流さず、**広告費ゼロで届けられる1経路**でLPを見てもらい、**相談1件→成約1件**を最優先にする。

---

この「1つ変える→数字を見る」を**1回でもやり切る**と、「自分で回したときの数字」が初めて手に入ります。  
10年分の知識は、**この数字の前後で使う**と、「何を磨くか」の判断がはっきりします。  
崖っぷちのときは、**「数字」＝相談1件・成約1件**をまず作ることに集中する。

### そのあとで「型を磨く」を再開したいとき

- 上記の**数字が出たあと**に、「相談予約は増えたが成約が少ない」などの**次の課題**が見えたら、  
  その課題にだけ**アドバイザーで推奨型を聞く**（例：成約が少ない → ウォーミング配信 or ステップメールの型）。
- **推奨型は1つだけ**選び、**それに沿って触るのも1箇所だけ**（例：相談予約後の1通目メールだけをウォーミング型で書く）にすると、「何をどうしていいかわからなくなる」が起きにくくなります。

### 訴求の切り替えと「アクセスはあるが申し込みが無い」ときの切り分け

**背景**  
「そもそもターゲットへの訴求がずれているのでは？」という見直しから、**マンガを作りたい人 → 資産形成したい人**に切り替えて広告を仕切り直している。  
前回は**アクセス単価は低くアクセスはあるものの申し込みが無かった**ため、今回は訴求を資産形成に寄せている。方向性は合っていると思うが、**いまいちエンジンがかからない**状態。

**現状の整理**

| 項目 | 状態 | 意味 |
|------|------|------|
| 広告creativeの方向 | **大当たり**と言われている | 資産形成訴求の方向は合っている |
| アクセス単価 | **約30円で推移** | クリック単価は悪くない。トラフィックは入っている |
| 申し込み | **無い（or 極少）** | **LP〜申し込みボタン**のどこかで落ちている |

**「エンジンがかからない」＝アクセスは来ているが、申し込みに繋がっていない**  
＝ 広告（入口）は機能しているが、**LP〜申し込み（出口）**で離脱している可能性が高い。

**申し込みを増やすための1箇所チェック（切り分け用）**

変数は**1つずつ**疑う。いまは「広告は大当たり・単価30円」なので、**LP側**を中心に下記を順に確認する。

| 確認ポイント | 問い | いまのLPで見る箇所（目安） |
|--------------|------|----------------------------|
| **広告→LPの一貫性** | 広告で「資産形成」を訴求しているなら、LPのファーストビューも「資産形成」で一貫しているか。マンガ・電子書籍の話が先に出ると、「自分向けじゃない」と離脱しやすい。 | ファーストビューの見出し・リード（例：「月20万の不労所得」「Kindle印税シミュレーション」）が資産形成・副収入で揃っているか。 |
| **「この相談は自分ごと」と思えるか** | 資産形成したい人が、**3秒で**「この相談、自分に関係ある」と思えるか。 | 冒頭〜動画前までの文言が「収入・副収入・印税・資産」で刺さるか。 |
| **動画→申し込みの流れ** | 動画視聴後、**そのまま申し込みに進む理由**が伝わっているか。「相談で何が得られるか」が一言でわかるか。 | 動画直下のCTA・リード。「無料個別相談」「〇〇が得られます」が短く出ているか。 |
| **申し込みのハードル** | 1,100円・フォームの項目数・「しつこくされそう」という不安が、申し込みを止めていないか。 | 「実質無料」「相談だけでもOK」が十分に見えているか。フォームが長すぎないか。 |
| **CTAの見え方・文言** | 「個別相談に申し込む」が、**視線の流れ・色・大きさ**で押しやすくなっているか。文言が「資産形成したい人」向けに刺さっているか。 | ボタン文言（例：「無料でシミュレーションをもらう」「資産形成の第一歩を相談する」など）。 |

**次の一手（1つに絞る）**

- **エンジンがかかる＝申し込みが1件でも増える**ところに集中する。  
- 上記のなかで、**「広告とLPの一貫性」**か**「ファーストビューで自分ごとと思うか」**の**どちらか1つ**だけを変えて、短期間だけトラフィックを流し、申し込みの有無を見る。  
- 例：ファーストビューの**見出しを1行だけ**「資産形成したい人向け」に寄せる、または動画上の**CTA文言を1つだけ**「無料で資産シミュレーションをもらう」のように変えてみる。  
- **変えるのは1箇所・1表現**にし、他は触らない。それで申し込みが増えた・増えなかったで、「訴求の一貫性」か「ハードル」のどちらを次に掘るか決める。

**まとめ**  
訴求を**マンガ→資産形成**に切り替えた方向は、広告creativeが「大当たり」・単価30円で推移しているなら**入口は合っている**。  
いま足りていないのは**LP〜申し込みまでの「資産形成したい人に向けた一貫した流れ」と「申し込む理由・ハードル」**のどちらか（または両方）の可能性が高い。  
**1箇所ずつ変えて申し込みの有無を見る**と、「どこでエンジンがかかるか」が分かりやすくなる。

## 2. 実行の流れ（今日すぐやること）

### ステップ1：アドバイザーを開く

1. **マーケティング**フォルダ内の  
   `商品に最適な型を提案するアドバイザー_プロンプト.md`  
   を開く。
2. 中の **「アドバイザー用プロンプト（コピー用）」** のブロック全体をコピーする。
3. **ChatGPT／Claude／Cursor** の**新規チャット**の最初のメッセージに貼り付けて送る。

### ステップ2：商品情報を渡す

4. **上記「商品・状況の入力」ブロック全体**をコピーする。
5. 同じチャットの**2通目**として貼り付けて送る。

### ステップ3：推奨型と「次にやること」を受け取る

6. AIから **「推奨型」「理由」「次に参照すべきファイル」「次のアクション」** が返ってくる。
7. その内容のうち **「次に参照すべきファイル」** を控える。  
   例：「ウォーミング配信（ベディヴィア）の 001プロンプト」など。

### ステップ4：LP・広告に応用する

8. **lp-consultation** と **マンガツール** の対応（下の「3. どこに何があるか」）を見ながら、次のどれに当てはめるか決める：
   - **LP・広告コピー** … ティザーポスト／オプトインLP の型を参考に、訴求文・見出しを揃える。
   - **相談予約後のメール** … ウォーミング配信／ステップメール の型で、温め→ツール案内の流れを組む。
   - **高額販売するなら** … 10分オファー動画（シルバプログラム型）や高額ステップメールの型を、相談→動画／メールに落とし込む。

9. **推奨されたフォルダのプロンプト・ナレッジ**を開き、その型に沿って  
   - lp-consultation の LP文言・構成、または  
   - 広告コピー、または  
   - 相談予約後用のメール案・ステップ設計  
   のどれかを作成・修正する。

## 4. 広告・LPへの「型の当てはめ方」例

アドバイザーから「ウォーミング配信が向いている」などと言われた場合のイメージです。

| 推奨された型 | lp-consultation・広告への応用の仕方 |
|--------------|------------------------------------|
| **ティザーポスト（ガウェイン）** | 広告の短い訴求や、SNS投稿の「興味を引く一行」を、ティザー型で量産する。30-1〜30-5 のテーマを、ガウェインのプロンプトで「見たくなる見出し」に整える。 |
| **オプトインLP（パーシヴァル）** | 「無料個別相談」の申し込みページを、オプトインLPの型（見出し・ベネフィット・CTAの流れ）で整理する。index.html の構成チェックや文言の差し替えに使う。 |
| **ウォーミング配信（ベディヴィア）** | 相談予約後に送る「まだ売らないメール」を、ウォーミング型で設計する。Kindle印税・マンガ制作の話で教育し、のちにツール案内やセールスに繋げる。 |
| **ステップメール／分岐後即セールス** | 相談予約から「ツール案内・オファー」までを、ステップメールの型（6つの教育や分岐後即セールス）で設計する。sales-talk-script や demo と連動させる。 |
| **10分オファー動画（シルバプログラム型）** | 高額で「動画＋LP＋ボタン」で売るなら、相談で見せる動画や、LPに埋め込むオファー動画の台本をシルバプログラム型で作る。 |

## 5. すぐやるチェックリスト

**「自分では売ったことがない／何をすればいいかわからなくなる」ときは、まず「0. 知識はあるが自分では売ったことがない人へ」を読む。**  
昨日LPの動画を作り替えた直後なら、「形をまた磨く」より**今の形のまま回して数字を見る**ことを最優先に。  
**「予算はあまりない・実験はできない崖っぷち」**のときは、広告で流すのではなく**「予算がほとんどない・実験できない崖っぷちのとき」**の表に従い、**広告費ゼロで1経路＋相談1件→成約1件**を最優先に。

**数字を見たあと**に、型を選び・磨く流れに進む場合：

- [ ] `商品に最適な型を提案するアドバイザー_プロンプト.md` を開き、アドバイザー用プロンプトをコピーした
- [ ] 新しいチャットにそのプロンプトを貼り、1通目で送った
- [ ] このファイルの「1. 商品・状況の入力」ブロックをコピーし、2通目で送った
- [ ] 返ってきた「推奨型」「次に参照すべきファイル」をメモした
- [ ] 推奨型に合わせて、上記「4. 型の当てはめ方」のどれをやるか決めた
- [ ] lp-consultation または マーケティング の該当フォルダを開き、LP／広告／メールのどれかに型を反映しにいった

---

*lp-consultation と マンガツール群 を、「売りたいもの」と「いまのLP・広告」として固定し、アドバイザーで型を選び、その型をLP・広告に応用するまでの手順です。*
