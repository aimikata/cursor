# 分岐後即セールス型ステップメール完全構築ガイド

## 1. 基本設計と重要な考え方

### 1.1 分岐後即セールスの特性と効果
```
【読者の特徴】
・メインメルマガからの分岐者
 - すでに著者を知っている
 - 価値観に共感している
 - 商品・サービスへの興味が高い

【3日間で決断を促す理由】
・興味が最も高いタイミング
・競合との出会いを防ぐ
・決断力のある優良顧客を選別
・熱が冷めないうちに決断

【時間をかけない理由】
・興味の薄れを防ぐ
・他の選択肢との比較を防ぐ
・優良顧客の即断即決を促す
```

### 1.2 セールス方式の選択と効果
```
A) 面談方式
【適している商品・サービス】
・高単価
・カスタマイズ要素が強い
・継続的なサポートが必要
・信頼関係が重要

【効果】
・不安要素の解消
・ミスマッチの防止
・信頼関係の強化
・成約率の向上

B) WEB決済方式
【適している商品・サービス】
・即時提供可能
・標準化されている
・説明が比較的シンプル
・価格が分かりやすい

【効果】
・即時の決断促進
・導線の単純化
・運用コストの削減
・スケールの容易さ
```

### 1.3 配信スケジュールの意図
```
【Day 1（4通）の狙い】
・登録直後：興味が最高潮の時に価値を提示
・5分後：確実な情報到達と重要性の認識
・1時間後：選別姿勢で価値を高める
・19時：価値観共有で信頼構築

【Day 2（3通）の狙い】
・7時：朝一で核心的価値を印象付け
・12時：昼休みの決断を促す
・19時：他者の声で後押し

【Day 3（3通）の狙い】
・7時：最終日の意識付け
・19時：ラストチャンスの認識
・23時：見逃し損失の実感
```

## 6. 実装時の重要ポイントと注意事項

### 6.1 メールの信頼性を高める要素
```
【文章の基本】
・一文を短く
・改行を効果的に
・重要点は独立した行に
・読みやすさ重視

【信頼性を損なう要素】
・誇大表現
・非現実的な約束
・根拠のない数字
・曖昧な表現

【解除URLの扱い】
・必ず毎回記載
・最下部に配置
・再登録不可を明記
```

### 6.2 セールスの質を高める実装
```
【面談方式の場合】
・審査の意義を説明
・面談の価値を提示
・時間の使い方を明確に
・不安解消ポイントを強調

【WEB決済の場合】
・即時開始のメリット
・手続きの簡単さ
・サポート体制の説明
・開始までの流れを明確に
```

### 6.3 効果測定と改善ポイント
```
【重要な測定指標】
・開封率の推移
・クリック率の変化
・申込率の計測
・成約率の把握

【改善の着眼点】
・開封されないメール
 → タイトルの改善

・クリックの少ないメール
 → 本文構成の見直し

・申込みの少ない日
 → 価値訴求の強化

・成約率の低下
 → 不安要素の特定と解消
```

### 6.4 最終チェックリスト
```
【配信前の確認事項】
・スケジュールの設定
・リンクの動作確認
・表示崩れのチェック
・解除URLの確認

【内容の確認項目】
・価値提示の明確さ
・ストーリーの一貫性
・決断を促す要素
・信頼性を損なう表現の有無

【セールス面の確認】
・商品価値の説明
・参加方法の明確さ
・締切の明示
・問い合わせ先の記載
```
