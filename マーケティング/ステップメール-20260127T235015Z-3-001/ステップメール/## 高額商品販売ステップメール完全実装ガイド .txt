## 1. 基本フレームワーク

### 1-1. 全体構造
```
配信期間：10日間
総配信数：23通
主要目的：高額商品販売（NAF）
入口商品：無料コンテンツ（EMS）

【構造的特徴】
・プレゼント起点での信頼構築
・4話構成の動画シリーズ
・複数プラットフォーム連携
・段階的な価値提供
・時間制限による締切
```

### 1-2. メディアミックス設計
```
【主軸】ステップメール
・セールスの本線
・価値提供の基盤
・信頼構築の軸

【補完】YouTube
・朝の3分動画
・メインコンテンツ（4話シリーズ）
・継続的な価値提供

【追加】LINE
・即時性の確保
・関係性の強化
・追加価値の提供
```

### 1-3. 段階的展開の基本設計
```
Phase 1: 価値提供・信頼構築
・プレゼント提供
・問題意識の共有
・価値観の共有

Phase 2: 教育・動機付け
・4話構成の展開
・具体的な方法論
・成功事例の共有

Phase 3: セールス・決断促進
・商品価値の提示
・期限の設定
・決断の促進

Phase 4: フォローアップ
・追加価値の提供
```


## 3. メール種別の実装パターン

### 3-1. プレゼント提供型メール
```
【基本構造】
件名：【※重要】[プレゼント名]のプレゼントです。
導入：即時の価値提供
本文：プレゼントの価値説明
締め：次への期待感醸成

【具体例】
原文：
「メルマガ登録ありがとうございます。

登録時に約束していた
プレゼントはこちらから
視聴してください。

━━━━━━━━━━━━━━
１商品１００万円までなら
対面・無料相談・勉強会・ZOOM無し
オンラインのみでガンガン売れる
放置型商品販売「EMSメソッド」とは？

※残り１０日で公開終了です。
━━━━━━━━━━━━━━」
```

### 3-2. 動画コンテンツ誘導型メール
```
【基本構造】
件名：具体的な価値＋数字を含む
導入：価値の予告
本文：具体的なベネフィット
締め：視聴の緊急性

【具体例】
原文：
「労働時間わずか１日２分で
　　  月収３１５９万円の
　　安定収入が生まれた日

　　　　▼第１話▼
　　自動で入金され続ける
●千万円の銀行口座を大公開!!

※間もなく公開終了します。」
```

### 3-3. 緊急性創出型メール
```
【基本構造】
1. 残り時間の明示
2. 行動しない場合の損失
3. 即決の重要性
4. 具体的な締切時間

【具体的フレーズ例】
段階1：
「間もなく公開終了します」

段階2：
「残り3日で完全にページに
アクセスできなくなります」

段階3：
「よくある煽りではなく、
マジで"2日後には完全終了"し
ページが一切見られなくなります」

最終段階：
「本日の23時59分で完全終了です」
```

### 3-4. ストーリーベース型メール
```
【基本構造】
1. 過去の状況提示
2. 問題点の説明
3. 転換点の描写
4. 成功体験の共有

ノウハウも無ければお金も無いし、
あるのは学校から帰宅後の時間だけ。

僕はどうやったら商品が売れるんだろう？
そうやって一生懸命考えました。

そこで「レビュー」を思いついたのです。
[...]
いや〜めちゃくちゃ嬉しかったですよ。」
```

```

【本文の最適化】

2. 問題解決型
```
