# ネオオートメーションフォーミュラ ステップメール問題点の教育編

## 1. 問題点の教育の本質

### 究極の目的
- 読者に問題点を認識させ、その解決策としてあなたの商品を選ばせる
- 最終目標：「あなたの商品がベストだと思えるように選択肢を徹底して絞る」という一点に集約

### なぜ必要か
- 人間は選択肢が多いと迷い、決断できない
- 世の中には無数の選択肢が存在する
- あなた以外のメルマガ発行者やビジネス実践者は全てライバル
- 多くのライバルの中からあなたの商品を選んでもらう必要がある
- 選択肢を絞らないと商品は絶対に売れない

## 2. 問題定義の具体的手法

### Step 1: 目的達成の障害を特定
- 設定したゴールを達成できない理由を徹底的に洗い出す
- 読者に「自分にもこの問題がある」と認識させる

### Step 2: 問題定義の具体例（業界別）

#### ビジネス自動化の場合：
1. インターネット活用の問題
   - オフラインビジネスへの固執
   - コーチ・コンサルタントの対面依存
   - 実店舗経営者のオンライン軽視
2. ステップメール未導入
   - 自動化の本質的理解の欠如
   - 効果的なツールの認識不足
   - 導入への躊躇

#### 集客の場合：
1. 広告活用の問題
   - Facebook広告未使用
   - YouTube広告未使用
   - 広告予算の未設定
2. 集客方法の誤認
   - オーガニック集客への過度な依存
   - 効果的な広告運用知識の不足

#### モテ・恋愛の場合：
1. 外見の問題
   - ファッションへの無関心
   - 清潔感の欠如
   - 髪型への無頓着
2. コミュニケーションの問題
   - 会話力の不足
   - LINE運用の未熟さ
   - 初対面での印象管理の失敗

## 3. 選択肢を絞る具体的手順

### 3-1. 間接的ライバルの否定（業界別詳細）

#### 筋トレプログラムの場合：
1. 各種ダイエット法の否定
   - トマトダイエット
   - 朝バナナダイエット
   - グレープフルーツダイエット
2. ダイエット器具の否定
   - 正しいフォームの重要性強調
   - 器具依存の危険性
3. 食事制限の否定
   - 栄養バランスの崩れ
   - リバウンドのリスク
4. 効果的な否定の具体例：
```
「私もトマトダイエットを試しました。
しかし満腹感が得られず、つい間食してしまい、
結果的に白米を大量に食べることになりました。
トマトスープも満足感が不足し、
リゾットにしてカロリーオーバーになってしまいました。」
```

#### メルマガアフィリエイトの場合：
1. 一般的な職業の否定
   - サラリーマン生活
   - アルバイト
   - 主婦業
2. 他のビジネスモデルの否定
   - 転売ビジネス
   - ネットワークビジネス
3. 効果的な否定の具体例：
```
「サラリーマン時代、残業を重ねても
月給は2000円程度しか上がらず、
年間でたった24000円の増加。
ボーナスもわずかな上乗せだけで、
理想の収入には程遠いことに気づきました。」
```

#### ライフスタイルコーチングの場合：
1. 自己啓発商品の否定
2. 占いへの依存の否定
3. 代替的な趣味の否定
   - 英会話教室
   - ゴルフレッスン
   - その他の習い事
4. 甘い考えの否定
```
「時間が解決してくれる」
「いい時期が来れば変わる」
という考えが最大の障害
```

### 3-2. 直接的ライバルの否定（業界別詳細）

#### 筋トレプログラムの場合：
1. 従来のトレーニング法の否定
2. 他の筋トレプログラムの否定
3. 差別化ポイントの強調

#### メルマガアフィリエイトの場合：
1. 他のアフィリエイト手法の否定
   - ブログアフィリエイト
   - ツイッターアフィリエイト
   - 従来のメルマガアフィリエイト
2. 独自性の強調
   - 例：「文章力不要のシステム」
   - 例：「コピペで完結する手法」

#### ライフスタイルコーチングの場合：
1. 従来のコーチング手法の否定
2. 他のコーチングプログラムの否定
3. 独自メソッドの価値提示

## 4. 効果的な否定手法（著者推奨メソッド）

### 4-1. 基本原則
- 直接的な否定は絶対に避ける
- 説教調は必ず離脱を招く
- 「これはダメだ」という言い方は厳禁

### 4-2. 推奨される否定方法
1. 個人的経験を活用した否定
   - 自身の失敗談
   - 克服までの過程
   - 気づきのストーリー

2. 周囲の経験を活用した否定
   - 友人の体験談
   - 家族の経験
   - 顧客の声
   - 飲み会での会話

3. 論理的な否定
   - データに基づく説明
   - 科学的根拠（ある場合）
   - 具体的な数値

### 4-3. ストーリーテリングの具体的手法
1. 過去の自分の経験を語る
2. 気づきのプロセスを共有
3. 現在の立場からアドバイス
4. 読者への共感を示す

## 5. 実装時の重要注意点

### 5-1. 必須要素
- 間接的ライバルの否定
- 直接的ライバルの否定
- 生き方自体の否定
- 考え方の否定
- ストーリーを使った説得

### 5-2. 致命的な失敗パターン
- 直接的な否定
- 説教調の文章
- 根拠のない否定
- 感情的な否定
- ライバル商品の軽視

### 5-3. 成功のための重要ポイント
- 読者は真剣に考えていない前提で書く
- 選択肢を絞ることを最優先する
- 否定は必ずストーリーベースで行う
- 自分の商品の独自性を際立たせる
- 全ての要素を漏れなく含める

## 6. 執筆プロセス

### 6-1. 準備段階
1. 要素出しを徹底的に行う
2. ライバルとなるものをリストアップ
3. 否定に使用するストーリーを用意

### 6-2. 執筆段階
1. 問題定義から始める
2. 間接的ライバルの否定を展開
3. 直接的ライバルの否定を展開
4. ストーリーを効果的に配置
5. 自然な流れを作る

### 6-3. チェックポイント
- 全ての要素が含まれているか
- 直接的な否定を使っていないか
- ストーリーは効果的か
- 選択肢は十分に絞れているか
- 読者視点で分かりやすいか

## 7. 最終確認事項
- 全ての選択肢を潰せているか
- ストーリーは具体的か
- 説教調になっていないか
- 根拠は明確か
- 独自性は際立っているか
