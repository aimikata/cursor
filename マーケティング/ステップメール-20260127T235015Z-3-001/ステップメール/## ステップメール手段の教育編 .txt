# ネオオートメーションフォーミュラ ステップメール手段の教育編

## 1. 手段の教育の根本原理

### 位置づけと目的
- 問題点の教育の後に実施
- 読者が認識した問題を解決するベストな手段を示す
- 「あなたの商品がベストだと思えるように選択肢を徹底して絞る」が究極の目的

### 3つの教育ステップ（順番厳守）
1. 自分の商品ジャンルがベストな理由の確立
2. 商品の選び方・提供形式に関する教育
3. 自社商品がベストである理由のこじつけ

## 2. 商品ジャンルのベストポイント確立法

### 基本アプローチ
- これまでの問題点教育で絞った選択肢をさらに絞る
- ストーリーを使って他の選択肢を否定
- エビデンス（論文・データ）があれば活用
- 世界的権威の意見も活用可能

### 業種別の具体的展開例

#### メルマガアフィリエイトの場合
```
- リストを持つことの強み
  ✓ SNSアカウント停止の影響なし
  ✓ SEOアップデートの影響なし
  ✓ 何度でも営業可能
  ✓ 完全な自分の資産になる

- 失敗事例を用いた否定
  「私も月1000万近く上がっていた
  アフィリエイト報酬が、
  わずか3ヶ月でほぼゼロになりました。
  広告アカウントが停止され、
  再起不能になった事例も
  たくさん見てきました。」

- PPCアフィリエイトバブルの例
  「月100万稼ぐ人が続出しましたが、
  規約変更とアカウント停止で
  一瞬で消えました」
```

#### Facebook広告の場合
```
- 圧倒的な費用対効果
  ✓ 低予算でテスト可能
  ✓ AIによる自動最適化
  ✓ 初心者でも結果が出やすい
  ✓ 他の広告媒体より使いやすい

- 具体的な強み
  「最も費用対効果が良く、
  低予算からテスト可能。
  FacebookのAIが自動で
  ターゲットを最適化するため、
  初心者でも結果が出やすい」
```

#### 筋トレプログラムの場合
```
- 根本的な効果の強調
  ✓ 基礎代謝アップ
  ✓ 太りにくい体質への変化
  ✓ リバウンドしない
  ✓ 見た目の改善

- 否定すべき一般的なダイエット法
  ・トマトダイエット
  ・朝バナナダイエット
  ・グレープフルーツダイエット
  ・ダイエット器具
```

## 3. 商品提供形式の選定と否定の技術

### 講座系の提供形式一覧
1. 対面コンサル
2. 通話コンサル
3. グループコンサル
4. セミナー・勉強会
5. デジタルコンテンツ
6. オンライン講座
7. 書籍
8. DVD
9. 音声教材

### 形式別の具体的否定文例

#### 対面コンサルを推す場合の他形式否定例
```
【通話コンサルの否定】
「通話では何を読んでいるのか分かりにくく、
情報の質も量も対面より劣ります。
講師がサボっているとしか思えません。」

【グループコンサルの否定】
「6人集めて1時間のコンサルなら、
あなたの時間はたった10分。
みっちり学べず、成果が出ません。」

【デジタルコンテンツの否定】
「提供して終わり、が大半です。
メールサポートは返信が遅く、
具体的な回答も得られません。」
```

### 一般的メリットのデメリット化テクニック

#### 情報の一括提供を否定する例
```
「全情報を一度に受け取れるのは
一見メリットに思えますが、
これは販売者のエゴであり、
サポート放棄と同じです。

学校の先生は教科書を渡して
"はい、終わり"とはしません。
順序立てて教えるのは、
それが最も効率が良いからです。」
```

#### オンライン講座の否定例
```
「ボリュームは多いのに、
料金は対面コンサル並み。
しかも対面サポートはなく、
二人三脚は望めません。」
```

### 相互補完パターンの活用法
```
・対面コンサル＋通話（遠方対応）
・個別レッスン＋補完教材
※必ず主軸を明確にすること
```

## 4. 自社商品のこじつけ技術

### こじつけの基本原則
- たとえ他の成功者と意見が違っても押し通す
- 自分より稼いでいる人の意見は気にしない
- ソフトバンクの孫さんやビルゲイツの意見も気にしない
- あなたのターゲットに合わせた主張をする
- 自信を持って提供できる商品だからこそ強く主張

### 業種別こじつけ例文

#### メルマガアフィリエイト
```
「1日たった1リスト、月30リストで
毎月10万円の報酬。
通常のメルマガアフィリエイトは
大量リストが必要ですが、
私のノウハウは集客がほぼ不要。
これは革新的なノウハウです。」
```

#### Facebook広告
```
「1リスト500円の低価格で、
月間100-2000リスト獲得可能。
私が設定代行するので、
あなたは素材用意だけでOK。
24時間365日サポート付き。」
```

#### 筋トレプログラム
```
「たった1日10分、週3回、
30日で細マッチョに。
ジムも不要、自宅で完結。
動画を見て真似るだけ。」
```

## 5. 重要な執筆ポイント

### 選択肢絞り込みの鉄則
1. 必ず1つに絞る（複数選択肢は読者を迷わせる）
2. 「これもいい、あれもいい」は厳禁
3. あなたの商品がベストな理由を徹底的に主張

### 信頼構築のための注意喚起
- 業界のNGポイントを明確に示す
- 搾取的商法への警告を入れる
- 「私の商品を選ばなくても、この手の商品だけは避けて」と伝える

### 読者への価値提供の姿勢
- お客様の人生をプラスに変える使命がある
- 商品購入は知識習得の機会になる
- 結果が出なくても学びになる
- だからこそ強く推していく必要がある

## 6. セールスポイントの確立と強調

### 強調すべきポイントの選定
- 他との明確な差別化ポイント
- 独自の革新的な特徴
- 読者の不安を解消する要素
- 具体的な数値やデータ

### 効果的なストーリーの組み立て方
1. 問題提起から入る
2. 従来の解決策の否定
3. 自社商品の優位性提示
4. 具体的な効果・結果の提示
5. 行動を促すクロージング

## 7. 最終確認事項

### コンテンツチェックリスト
- [ ] 選択肢は完全に1つに絞れているか
- [ ] 他の選択肢の否定は論理的か
- [ ] ストーリーは具体的か
- [ ] 自社商品の優位性は明確か
- [ ] こじつけは十分か
- [ ] 注意喚起は効果的か
- [ ] 読者の行動を促せているか

### 避けるべき失敗パターン
- 選択肢を複数残す
- 自信なさそうな主張
- 他者の意見を気にしすぎる
- 論理的でない否定
- 具体性のない説明
