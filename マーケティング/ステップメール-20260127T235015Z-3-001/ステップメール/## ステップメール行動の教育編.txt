# ネオオートメーションフォーミュラ ステップメール行動の教育編

## 1. 絶対的大前提：人は行動しない

### コピーライティングの3大原則
1. 読まない
2. 信じない
3. 行動しない

### 行動しない人間の本質
- 基本的に人は何もしない
- 行動の重要性を言語化して伝える必要がある
- セールス前に背中を押す必要がある

### 実装のタイミング
1. 全ての教育（目的・信用・投資・手段・問題点）の後
2. 商品提示の直前
3. 最後の背中押しとして実施

## 2. 恐怖を使った行動促進の具体的メソッド

### 基本原理：損失回避の法則
- 得る喜び＜失う痛み
- 例：100円を得る vs 100円を失う
  - 50%の確率でも損失回避を選択
- ストーリーで恐怖を具体化する

### 業種別の具体的ストーリー展開

#### ビジネス自動化系
```
【失敗シナリオ】
「自動化せずに単発売上のまま...
・散財を続け
・貯金が底をつき
・家賃が払えず
・事務所維持も困難
・最終的には廃業

【実体験の追加】
実際、私も単発売上で
・高級車を購入
・タワーマンションに住み
・何千万も散財
今思えば愚かな選択でした」
```

#### ダイエット系
```
【現状維持の恐怖】
「82キロのまま続けていれば...
・今の奥さんと出会えず
・41歳で暗い独身生活
・体のあちこちが痛み
・休日は寝たきり
・入院生活のような毎日

【具体的な痛み】
・腰痛
・膝の痛み
・健康診断の悪化
※可能であれば実際の健康診断結果も提示」
```

#### サラリーマン向け
```
【社会情勢と連動】
・大企業のリストラ現実化
・副業解禁の流れ
・金融庁による年金破綻発表

【具体的な転落シナリオ】
1. 窓際社員への転落
2. 突然のリストラ
3. 正社員の職を喪失
4. 家族からの見放され
5. 一家離散の危機

※ニュースサイトや記事を引用して
　エビデンスとして提示」
```

## 3. 行動による人生好転の具体的提示

### 恐怖からベネフィットへの転換技術

2. 転換点となる行動の明示
3. 具体的な成功体験の共有
4. 現在の理想的な状態の描写

#### ビジネス系
```
「諦めずにチャレンジした結果...
・年収1億円を突破
・時間的自由を獲得
・家族との時間が増加
・自分の人生を自分で選択可能に

重要な転換点：
ここぞという時の一歩」
```

#### 恋愛系
```
「渋谷でのナンパ挑戦から...
・膝ガクガク状態から
・震える声で話しかけ
・それが人生の転機に
・今やモデルの彼女と交際
・人生がバラ色に

キーポイント：
たった一度の勇気ある行動」
```

## 4. 読者を行動させる具体的な仕掛け

### 即実践できる行動仕掛けリスト
1. アンケート回答依頼
2. 感想送付（プレゼント付き）
3. URLクリック
4. ポイント付与
5. 無料相談申込
6. 企画参加
7. 悩み相談
8. 無料通話コンサル
9. LINE・チャットワーク連絡

### 仕掛けの実装方法
```
【基本パターン】
1. 小さな行動要求
2. 適切な報酬設定
3. 次のステップへの誘導

【具体例】
・URLクリックで10ポイント付与
・感想送付でプレゼント進呈
・アンケート回答で特典提供
```

### 行動の連鎖を作る技術
```
【段階的アプローチ】
1. プレゼント目当ての小さな行動
2. 興味関心の深堀り
3. より大きな行動へのステップアップ
4. 最終的な商品購入

【重要ポイント】
・一度行動すると次も気になる
・興味が徐々に深くなる
・自然な流れを作る
```

### エビデンスの活用

## 6. 行動の教育における重要な注意点

### 避けるべき表現方法
```
×「無料情報を見る人はバカです」
×「行動しない人はダメ」
×「なぜ動かないのか」
```

### 推奨される表現方法
```
○「私も同じ失敗を」
○「あの時の決断が」
○「小さな一歩から」
```

## 7. 実装プロセス

### Step 1: ストーリーの準備

2. 具体的な数値の収集

### Step 2: 恐怖シナリオの構築

2. 具体的な損失
3. リアルな感情描写

### Step 3: 行動促進の仕掛け設計

2. 適切な報酬の決定
3. 段階的なステップアップ

### Step 4: フォローアップ体制
1. 行動後のサポート準備
2. 次のステップへの誘導
3. 継続的な関係構築
