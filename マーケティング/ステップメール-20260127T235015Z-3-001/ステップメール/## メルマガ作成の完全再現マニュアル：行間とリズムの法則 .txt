# メルマガ作成の完全再現マニュアル：行間とリズムの法則

## 第1章：基本フォーマット

### 1. 推奨フォーマット（トミー基本パターン）
```
こんにちは、トミー福沢です。

今日は、
「国から合法的にお金を奪う非道徳な裏技」
について話します。

あなたは今、
「え？国からお金奪うって犯罪じゃないの？」
と、思ったかもしれません。

しかし、これは合法で、基本的に誰でも
ルールに則ってしまえば手に入れられるのです。
```

### 2. 文章構造の基本ルール
- 「。」で1行空ける
- 話が変わったら2行空ける
- 1行は20文字前後以内
- 1文は最大4行まで（5行以上は分割）

### 3. 3つの行間パターン

#### A）トミー基本パターン（全ユーザー対応型）
- 「。」で1行空け
- 話が変わったら2行空け

#### B）事例①（中間型）
- 「。」で2行空け
- 話が変わったら3-4行空け

#### C）事例②（最大余白型）
- 改行で1行空け
- 「。」で2行空け
- 話が変わったら3-4行空け

## 第2章：リズム作りの具体的手法

### 1. リズム＝1行の長さの変化
悪い例：
```
銀行や公庫から借り入れをすることで
お金がザクザクと増えていきます。

「そりゃ当たり前だろ！」と
思ったかもしれませんね。

当たり前なのに使わないのは
何か理由があるんでしょうか？
```

良い例：
```
銀行や公庫から
借り入れをすることでお金が
ザクザクと増えていきます。

「そりゃ当たり前だろ！」
と思ったかもしれませんね。

当たり前なのに使わないのは
何か理由があるんでしょうか？
```

### 2. 強調テクニック
```
この"国のお金"の正体は…

「融資」

です。
```

### 3. リズムを作る接続詞の使い方
- 単独行での使用例：
```
しかし…

特に…

例えば、
```

### 4. 読みやすさを高めるデコボコパターン
```
⚫⚫⚫⚫⚫
⚫⚫⚫⚫⚫⚫⚫⚫
⚫⚫⚫⚫⚫⚫⚫
⚫⚫⚫
⚫⚫⚫⚫⚫⚫⚫⚫⚫
```
- 2行続きを避ける
- 3行、1行、2行など変化をつける

## 第3章：実践的な文章改善テクニック

### 1. 長文の分割方法
改善前：
```
実は１０００万以上の大きな融資でも比較的イージーに審査が完了する"裏口融資"と、借りたお金を返さなくて済んでしまう"他力本願億万長者スキーム"が実は存在するのです。
```

改善後：
```
実は１０００万以上の
大きな融資でも比較的イージーに
審査が完了する
"裏口融資"
と、
借りたお金を
返さなくて済んでしまう
"他力本願億万長者スキーム"
が実は存在するのです。
```

### 2. キーワード強調パターン
```
「コピーライティング」
これこそが億万長者への
最短ルートです。

我々の生きている世界では
"文字"はどこにでも存在しています。

特に…
ネットで稼ぐなら
文字を操り
人を扇動できるようになるべきです。
```

## 第4章：ターゲット層に応じた使い分け

### 1. 情報強者向け（真面目で能力の高い層）
- より詰まった文章構成
- トミー基本パターン推奨
- 行間を最小限に

### 2. 情報弱者向け
- より開いた文章構成
- 事例①または②を使用
- 行間を多めに

### 3. 反応率の法則
```
情報強者 ← トミー基本パターン < 事例① < 事例② → 情報弱者
```

## 第5章：完全チェックリスト

### 1. 行間のチェック
- [ ] 「。」での行空けは守られているか
- [ ] 話の切り替わりで適切な空行があるか
- [ ] 選択した行間パターンが一貫しているか

### 2. 文字数のチェック
- [ ] 1行20文字前後を超えていないか
- [ ] 1文が4行以上になっていないか
- [ ] 5行以上の文は適切に分割されているか

### 3. リズムのチェック
- [ ] 同じ行数パターンが続いていないか
- [ ] 接続詞を効果的に使用しているか
- [ ] 重要なフレーズは独立した行になっているか
- [ ] デコボコのリズムが作られているか

### 4. 強調表現のチェック
- [ ] 重要な単語やフレーズは独立行か
- [ ] 「"」や「」などの記号は効果的に使用されているか
- [ ] 接続詞による間の取り方は適切か

### 5. ターゲット層の確認
- [ ] 想定読者層に適した行間パターンを選択しているか
- [ ] 文章の密度は目的に合っているか
- [ ] 全体的な読みやすさは確保されているか
