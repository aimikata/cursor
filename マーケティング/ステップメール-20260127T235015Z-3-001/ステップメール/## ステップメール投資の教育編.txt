# ネオオートメーションフォーミュラ ステップメール投資の教育編

## 1. 投資教育の根本原理

### お金を払う苦痛の科学的理解
- MRIと神経研究による実証
  - お金を払う時は身体的苦痛を処理する脳の部位が活性化
  - 皮膚を摘まれる・殴られるような物理的な痛みと同等
  - 単なる心理的抵抗ではなく、実際の痛みとして知覚

### 教育のタイミングと段階設計
1. ステップメールでの事前教育
2. セールス動画での再教育
3. セールスレターでの補強
※重要：セールス時のみの教育は売り込み感が強くなり逆効果

## 2. 具体的な説得パターン（業種別）

### パターン1：知識・ノウハウ系
```
【基本フレーム】
「成功者は常に自己投資をしています。
本やコンテンツ、コンサルへの投資で、
著者や講師の5-10年の積み上げを
一瞬で獲得できます。
これは彼らの人生を買うようなものです。」

【具体的な数値例】
・3ヶ月→即時解決
・20万円相当→数万円
・Before→After（具体的数値）
```

### パターン2：サポート系
```
【基本フレーム】
「安い商品のデメリット：
・サポート品質が低い
・初心者には不向き
・講師の時間が取れない

高額商品のメリット：
・経済的成功者が多い
・上質な環境
・手厚いサポート
（高級ホテルの例えで説明）」
```

### パターン3：投資・トレード系
```
【失敗からの成功ストーリー】
「無料情報→4時間/日×3年
結果：100万円→2万円
有料コンサル（5万円）投資
結果：1年で220万円達成
教訓：98万円と3年を無駄に」
```

## 3. ストーリーテリング実装メソッド

### 効果的なストーリー要素（優先順位付き）
1. 自分の体験談（最も説得力が高い）
2. お客様の成功事例
3. 友人・知人の体験
4. 世界的権威の言葉
5. 影響力ある人物のエピソード

### ストーリー構築の基本パターン
```
1. 過去の失敗体験
2. 転換点（投資の決断）
3. 行動と結果
4. 得られた学び
5. 現在の状況
6. ベネフィット（生活の変化）
```

### 具体的な数値の入れ方
```
・投資額：具体的な金額
・時間：○ヶ月、○年
・結果：収入、売上の変化
・比較：投資額 vs 得られた利益
```

## 4. 損失回避フレームの実装

### 基本パターン
```
1. 無料情報での失敗期間
2. 無駄にした時間の提示
3. 逃した機会利益の計算
4. 有料情報での成功体験
5. 比較による損失の明確化
```

### 業種別の具体的な損失例
```
【ビジネス系】
「2年間の無駄：
・時間：2920時間（4h×730日）
・機会損失：24万円（1万×24ヶ月）
・精神的消耗
・家族との時間」

【投資系】
「3年間の損失：
・元本：98万円
・時間：4380時間（4h×1095日）
・精神的ダメージ
・やる気の低下」
```

## 5. 信頼構築のための否定手法

### 直接否定を避けるテクニック
```
×「無料情報を見る人はバカです」
○「私も無料情報で失敗しました」

×「安い商品は質が悪い」
○「高額商品だからできるサポート」

×「それではダメです」
○「私の経験では別の方法が」
```

### 体験談を使った否定パターン
```
1. 過去の自分の失敗
2. 友人の経験
3. クライアントの声
4. 業界の一般的な事例
5. 統計やデータ
```
