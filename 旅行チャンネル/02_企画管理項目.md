## 1. 企画ステータス

| ステータス | 意味 |
|---|---|
| Idea | 思いつき。未検証 |
| Research | 営業時間・移動・季節を調査中 |

## 4. 優先度の決め方

### P0（最初に作る）

- 保存されやすい（1日ルートが明確）
- 検索されやすい都市（大阪・京都・東京・沖縄など）
- Local Tipが強い
- 同じ型を横展開しやすい
- **海外向けに強い作品名の聖地巡礼マップ**（作品名が集客フックになる）

### P1

- 季節・イベント依存（公開タイミングが大事）
- ニッチだが差別化が強い（車椅子／雨の日／乗り継ぎ）
- 作品ファン向けの季節版・半日版・撮影重視版

### P2

- 見て楽しむ系の都市変化
- 派生バリエーション（同じルートの子ども連れ版など）
- 作品のニッチ派生（雨版、夜景版など）

## 5. 企画立案チェック（Idea → Research に進む条件）

- [ ] 視聴者の困りごとが一文で言える
- [ ] 「いつ／誰と／何のために」が決まっている
- [ ] Local Tipの種がある（まだ検証前でよい）
- [ ] 有名スポット羅列だけで終わらない理由がある
- [ ] 説明欄にしたとき旅行メモになる見込みがある

---

## 6. 旅程妥当性チェック（Research → Draft）

- [ ] 開業・開門に間に合う開始時刻か
- [ ] 移動（待ち時間含む）が現実的か
- [ ] 食事枠が死んでいないか
- [ ] 夕方〜夜の締めがあるか（1日物の場合）
- [ ] 雨・休業・行列の代替が1つあるか

## 7. シリーズ設計の型

同じ都市でも、次の切り口で増やせる。

| 型 | 例 |
|---|---|
| 同行者違い | 大阪1日 × 初めて / 子ども連れ / 車椅子 |
| 季節違い | 京都 × 桜 / 新緑 / 紅葉 |
| 時間違い | 東京 × 半日 / 夜だけ / 乗り継ぎ3時間 |
| 天候違い | 神戸 × 晴れ定番 / 雨の日屋内寄り |
| 目的違い | 福岡 × グルメ / 歴史 / 夜景 |
| 変化×歩き方 | 梅田の昔と今 → 今歩くならこの90分 |
| 作品×都市 | Iroduku × Nagasaki / Anohana × Chichibu |
| 作品×季節 | Your Name × Cherry Blossom / Euphonium × Autumn |
