# 旅行チャンネル制作ドキュメント

都市の変化を見るチャンネルから、旅を選べるチャンネルへ。

## コンセプト（一言）

**旅先を眺めるのではなく、そのまま旅を計画できる動画。**

目指すポジション：旅行版Netflix／動画版旅行プランライブラリ

## 使い方

1. 企画を立てる前に `00` で方針を確認する
2. 新規企画は `02` の管理項目に記入する
3. 台本・撮影・編集は `01` のテンプレートに沿う
4. 大阪第1弾は `03` をそのまま制作ブリーフとして使う
5. アニメ聖地巡礼は `04` を企画設計の正本とし、一カテゴリ扱いに落とさない

## 2本柱＋海外入口

1. **見て楽しむ動画** … 都市の昔と今、再開発、街並みの変化
2. **保存して使う動画** … 条件別の旅行プラン型ショート
3. **作品から選ぶ入口** … アニメ聖地巡礼マップ（海外集客の強い入口）

統合フレーズ：**都市の昔・今・歩き方**
