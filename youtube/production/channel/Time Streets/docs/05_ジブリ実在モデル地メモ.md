## いま聞かれた2点の答え

### 1. 『もののけ姫』× 世界遺産の島

思い出し中の島は、ほぼ確実に **屋久島（鹿児島）**。

| 項目 | 内容 |
|---|---|
| 場所 | 鹿児島県・屋久島（1993年 世界自然遺産） |
| 特に語られるスポット | **白谷雲水峡**の「苔むす森」 |
| 根拠の強さ | スタジオジブリ側でも「大いに参考にした場所」として屋久島が挙げられる（ファン・報道でも定番） |
| もう1つ | **白神山地**（青森・秋田）も「大いに参考にした」とされる（エミシの村周辺のイメージ等） |

補足：

- 作品の地名は架空。屋久島＝「シシ神の森そのもの」と断定しすぎない
- かつては「もののけ姫の森」と呼ぶ看板もあったが、踏み荒らし対策で呼称変更された経緯あり → 案内時は住民・自然保護の配慮必須

### 2. 湯婆婆の湯屋（油屋）×「文京区の銭湯／お寺」

記憶はかなり近いが、正確にはこう整理できる。

| 思い出し | 実際 |
|---|---|
| 文京区 | **ちがう**。銭湯の旧所在地は **足立区千住元町** |
| お寺 | **見た目が寺社風**（唐破風など「東京型銭湯」）。お寺そのものではない |
| 銭湯 | **正しい**。名前は **子宝湯** |
| 今どこ | **小金井市・江戸東京たてもの園**に移築保存 |

公式寄りの整理：

- **子宝湯（江戸東京たてもの園）** … 「商店街の一角にそびえ立つ銭湯」という油屋の設定にインスピレーションを与えた、とジブリ側でも言及あり
- **道後温泉本館（愛媛・松山）** … 宮崎監督も「道後は確かに入っている」と答えている系の公式寄り返答あり。絵コンテに「導後」の文字がある、という解説も有名
- 油屋は **単一モデルではなく複数の温泉・建築の合成**、というのが基本スタンス

文京区が出てくる理由の推測：

- 同じ江戸東京たてもの園に、**旧所在地が文京区向丘**の建物（仕立屋など）もある
- 子宝湯の外観が寺社建築に見える
- → 「文京区のお寺／銭湯」と記憶が混線しやすい
