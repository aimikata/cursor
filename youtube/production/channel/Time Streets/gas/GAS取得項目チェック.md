# いまのGASで「今回欲しい分析」は取れるか？

## 結論

**半分は取れています。ただし診断の最重要指標はまだ足りません。**

Time Streets の `CHANNEL_IDS` 指定は正しいです。  
一方で、今回やりたい「冒頭か中盤かを切り分けて、変更前→変更後まで出す」には、  
**視聴を選んだ割合** と **動画尺** が必須で、現行V2では動画尺も取っていません。

## いまのGASの良い点

- Time Streets ID `UCkD8_KvuA5egxWtW2vDmuKQ` だけを見る構成になっている
- 維持率・流入元・国別・検索まで取れ、需要と配信先の仮説は立てられる
- 「改善点を1つだけ」に絞る思想は今回の方針と一致

## いまのGASの問題点

1. **視聴を選んだ割合が無い**  
   → 冒頭負けか中盤負けかを切れない
2. **動画尺が無い**  
   → 同じ70%でも意味が違う
3. `ChatGPT入力用` の対象名が **`INSIGHT MANGA` 固定**  
   → Time Streetsなのに誤ラベル
4. 検索意図推定が不倫・毒親など **INSIGHT向け**  
   → Time Streets（旅程/聖地）に合わない
5. Shortsフィードは「表示数」ではなく、取れるのは多くて **フィード経由再生**

## 何をすればよいか

1. このリポジトリの `gas/TimeStreets_YouTubeDashboard_V2.1.gs` を Time Streets シートの GAS に貼る
2. メニュー → `1. 初期セットアップ`（列が増えるため）
3. `2. 今日の分析を取得` を実行
4. `Studio手動追記` タブに、重要動画だけでも  
   - 視聴を選んだ割合  
   - 維持率の最大下落秒数  
   - 現在の冒頭文  
   を入れる

これで、今回の診断（入口/中盤/需要/CTAの切り分け）に必要なデータが揃います。
