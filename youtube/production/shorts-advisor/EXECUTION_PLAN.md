# 意図の実行計画

## あなたがやりたかったこと（要約）

「伸びないから改善しろ」と言われても何をどうすればいいか分からない、を解消する。

具体的には:

1. アドネス記事の参考値を、公式指標の注意書き付きでチャンネル用に落とし込む
2. 数値を見て主原因を **1つだけ** 決める
3. 「冒頭を改善して」ではなく **変更前 → 変更後（英語＋日本語意味）＋理由＋成功判定** まで出す
4. 「次の新作で試す」のか「同じ動画を1点変更して再投稿して検証する」のかを分ける
5. その前提として、シートに診断可能な数値を揃える（ここが未完了だった）

対象チャンネル:

- **INSIGHT MANGA** … ストーリー・教育・感情ドラマ（維持75%以上目安）
- **I Entered the Story** … 歴史没入・Vlog・ストーリー（維持65〜75%、合格目安70%）

## 実行アーキテクチャ

```text
YouTube Studio（手動） ──┐
                         ├─→ metrics CSV / シート
YouTube Analytics API ───┘         │
  (取れる指標のみ)                  ▼
                         diagnose.py（主原因1つ）
                                   ▼
                         日次レポート.md
                         （変更前/後・理由・成功判定・再投稿or新作）
```

## 診断の優先順位（実装済み）

| 順位 | 条件 | 主因 | 提案の型 |
| ---: | --- | --- | --- |
| 1 | 視聴を選んだ割合 < 目安 | 冒頭1秒 | 自己紹介→事件の核心。危険帯なら再投稿A/B |
| 2 | 入口OKかつ平均視聴率 < 目安 | 中盤離脱 | 秒数指定で説明短縮＋予告挿入 |
| 3 | 維持OKだが再生が弱い | 需要/タイトル入口 | 編集よりテーマ約束を変更 |
| 4 | 再生はあるが反応が薄い | CTA弱い | 末尾の具体的な問いを指定 |

不足数値があっても、取れた数値から上記順で最も確度の高い1つを出します。

## 運用フロー（推奨）

1. 通常は新作を投稿する
2. 投稿後24時間で数値をシートへ
3. レポート生成 → 原因1つを確認
4. **特に改善価値のある動画だけ** 同一内容・1点変更で再投稿して検証
5. 結果を次の新作の型に反映

A/B成功の見方（厳格）:

- 視聴を選んだ割合が +10pt 以上
- 維持率が悪化していない
- Shortsフィード表示も増えた

別動画での同型繰り返しは「傾向確認」であり、厳密な検証ではない、とレポート上で明示します。

- 改善目安・チャンネル基準・提案テンプレのコード化

1. 両チャンネルの Studio から直近Shortsを `data/` のCSV形式で記入
2. 特に **視聴を選んだ割合** と **動画尺** と **現在の冒頭文** を入れる
3. `python scripts/generate_daily_report.py --csv data/your_metrics.csv` を実行
4. （任意）Google Cloud OAuth を用意できたら API 自動取得を有効化

### まだやらないこと

- 曖昧な「テンポ改善」「CTA強化」だけ返すこと
- 全動画を毎回再投稿すること（弱い動画の検証用に限定）
