# YouTube 制作一式

YouTube関連の正本はここに置きます。

## 場所一覧

| パス | 内容 |
| --- | --- |
| `channel/` | チャンネル別の正本（Time Streets など） |
| `channel/Time Streets/gas/` | **Time Streets用GAS（ここを見る）** |
| `shorts-advisor/` | Shorts改善診断ツール（共通） |
