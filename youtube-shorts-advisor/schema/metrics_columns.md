# シート必須項目

自動シート／CSVに最低限入れる項目です。

| 必須項目 | 用途 | Studioでの場所（目安） |
| --- | --- | --- |
| 動画尺 | 維持率の意味を判断 | コンテンツ → 動画の尺 |
| 視聴を選んだ割合 | 冒頭の強さ | アナリティクス → コンテンツ → 対象Short → リーチ「視聴者が視聴を選んだ割合 / How many chose to view」 |
| スワイプされた割合 | 冒頭の弱さ | 同上の裏返し（100 − 視聴を選んだ割合でも可） |
| 平均視聴時間 | 実際に何秒見られたか | エンゲージメント |
| 平均視聴率 | 尺に対する維持 | エンゲージメント「平均視聴率」 |
| いいね数 | 満足度 | コンテンツ / エンゲージメント |
| コメント数 | 能動的反応 | 同上 |
| シェア数 | 他人に勧めたい反応 | 同上 |
| Shortsフィード表示数 | 配信母数 | リーチ（Shortsフィード） |
| 登録者増減 | チャンネルへの貢献 | オーディエンス / コンテンツ |
| 維持率の最大下落秒数 | 具体的な修正位置 | 視聴者維持率グラフの崖 |

特に重要なのは **視聴を選んだ割合** と **動画尺** です。  
これがないと、平均視聴率だけ見て「冒頭が悪いのか、中盤が悪いのか」を切り分けられません。
